# Next.js Frontend

This directory contains a minimal Next.js application that fetches solar power data from the Flask API.

## Development

1. Install dependencies (requires Node.js):
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open your browser at `http://localhost:3000` to view the app.

The frontend expects the Flask API to be running on `http://localhost:8888`.
