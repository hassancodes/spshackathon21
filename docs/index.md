# NASA-Based Plant Prediction Software

Welcome to the documentation for the NASA-Based Plant Prediction Software. This application integrates NASA's Power API to provide solar power data and basic crop information.

## Getting Started
1. Install Python 3.x.
2. Install dependencies:
   ```bash
   pip install -r src/requirements.txt
   ```
3. Run the application:
   ```bash
   python src/main.py
   ```
4. Open your browser to `http://localhost:8888`.

## Running Tests
Run unit tests with:
```bash
pytest
```

## GitHub Pages
This directory is used for GitHub Pages. After committing documentation here, enable GitHub Pages in the repository settings and select the **main** branch with the `/docs` folder as the source.
